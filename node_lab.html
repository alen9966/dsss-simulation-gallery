独立段 / 预算 / 统计：
必须关注：捕获起点 → 有效Prompt → 归一化输出事件 → Costas判决 → 完整载荷。任一必要输出缺失，都不能判为通信完成。真实FFT连续cap_valid、FIFO/CDC、LVDS对齐、RF时标尚未由本界面观测。

示波器记录保持，频谱逐窗累加

高速I/Q按固定长度采集记录刷新；新节点数据未到时保留上一完整记录，不再把图清空。频谱采用2048点Hann窗、50%重叠的短时FFT功率平均，并保留64条瀑布。这是显示仪器旁路，和接收机FFT相关捕获相互独立。

低速环路状态保持一条连续时间轴

Prompt、归一化、Costas与DLL等低速状态画成连续趋势线。下一段继承载波相位、DLL/Costas和相噪状态，绝对仿真时间、段号和累计统计不清零；每段仍重新捕获报文。

哪些来自工程，哪些仍需商榷

通信结构以原Vivado工程为依据；AD9361初始化顺序和FIR API来自Plutosdrmini No-OS例程；例程PL接口是12 bit CMOS DDR，底板1.8 V LVDS只能参考I/Q边沿和延时校准思想。旧70 MHz DUC及外部DAC/ADC在迁移后由AD9361内部FIR/HB、DAC/ADC和RF链替代。

功能算法 / 当前COE特性 / 独立数学诊断分别标注；截图不等于完整RTL、实际Simulink框图或硬件验收。
